# Chinese reference documents

This directory preserves the original Chinese specification text during the English-default migration. It is a historical reference, not a second active specification tree.

The current English contracts are in [`../specs/`](../specs/). Where older text requires Chinese proposal names, Chinese-only output, fixed external subagents, or historical workflow limits, use the current English specification and the generation-specific compatibility behavior in code instead.

Historical proposal archives and one-off demonstration/debug records are kept in the private pre-publication backup rather than shipped as product documentation. Long-lived executable tests remain in `tests/`.
